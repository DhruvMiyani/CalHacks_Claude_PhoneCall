## 🚀 Usage

To apply any of these styles to your timezone converter:

1. Copy the desired style template:
   ```bash
   cp templates/styles/[STYLE_NAME].html templates/index.html
   ```

2. Restart your Flask app or refresh the browser

3. Visit http://127.0.0.1:5000 to see the new style
